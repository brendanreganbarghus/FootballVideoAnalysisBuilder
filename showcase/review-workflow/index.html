Review Canvas for Beginners

Evidence first. User decision. Code only when required.

The Canvas keeps the rules engine and Copilot independent, then guards every accepted event with fresh fingerprints and regression tests.

Watch Evidence

Use video, tracking, calibration, and match state.

Build C# Alone

04 · Compare

Match C# ↔ E#

Compare type, team, and timestamp only afterward.

05 · Decide

You Authorize

Accept, reject, adjust, or add the reviewed event.

Accepted C# + Exact Fresh E# → No Code Change

Both source and output hashes match, and the engine already produces the accepted event.

Accepted Event Missing from E# → General Rule Change

Copilot updates reusable football logic, rebuilds cached events, and reruns focused plus protected tests.

Rejected C# → Exclude the Proposal Only

Rejection does not prove or confirm any nearby engine event.

Unmatched E# → Verify It Independently

Inspect its own targeted evidence before recording a confirmation receipt.
