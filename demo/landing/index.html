We don’t treat an AI prediction as an unquestionable fact. Each event type is progressively detected, tested, checked against football rules, and reviewed before it is allowed to contribute to the statistics layer. The target for validated events is roughly 90–100% confidence — that is the methodology we are working towards, not a claim already achieved across every event type.
